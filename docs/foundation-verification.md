# 应用基础验证记录

日期：2026-11-12。本记录只覆盖 OpenSpec 第 2 组基础能力，不表示已完成嵌入、ERP 身份、Agent 或采购闭环。

- Python 3.14.10、uv 0.13.7、Node 26.13、PostgreSQL 18；具体依赖使用仓库锁文件。
- 从新建本地 `.env`、新 PostgreSQL 卷启动，执行 Alembic 初始迁移；真实数据库健康检查和无令牌 ERP 契约探针通过。
- 无效加密密钥、不可连接数据库和不可连接 ERP 的真实启动进程均失败，合成秘密标记没有出现在输出中。
- PostgreSQL 集成用例覆盖空库迁移、不同连接/租户/用户隔离、数据库复合归属外键、并发消息去重、明确忙碌、事务回滚、并发领取、租约过期与过期 worker 拒绝、有限尝试耗尽。
- 真实子进程领取工作后退出；新子进程在租约过期后完成同一工作，原消息与 outbox 没有丢失。
- 在随机 schema/数据库执行 pg_dump/pg_restore，恢复的虚构任务 ID 和归属一致，演练对象随后清理。
- 持久化事件生成器验证断流后补发、游标边界、匿名/其他归属拒绝、重复读取不新增 job；浏览器验证开发页的虚构事件状态和去重。浏览器测试区不表示已对真实身份完成 SSE 测试。
- React 类型检查、事件 reducer 测试和 Vite 生产构建通过。同源入口实测为 `http://127.0.0.1:18081/assistant/`；开发服务独立使用 18000/5173。
