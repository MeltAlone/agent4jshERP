# 侧边栏使用与布局验收

本次调整于 2026-11-13 在内置 jshERP 独立栈验证。目标是让普通使用者打开助手即可对话，并在需要时找到历史、任务和页面上下文。

## 日常使用

- 顶部时钟图标打开历史会话，可搜索标题、切换或新建。标题默认取首条用户消息，时间为创建时间；仅显示当前身份的会话。
- 右上角新建按钮进入空白对话，发送首条消息后才保存会话。新建或切换会话不会取消后台任务，也不会确认采购。
- 中间只有一个消息滚动区；底部输入框保持可见。Enter 发送，Shift + Enter 换行。向上翻阅后可用“回到最新”回到底部。
- 会话有任务时显示任务图标。选择后“正在跟进”标签说明后续消息的任务范围；关闭标签回到普通会话。聊天记录仍按时间显示，服务端的任务记忆与业务草稿保持独立。
- 输入框上方显示当前页面摘要。点击查看选中记录的使用方式；只有显式新建任务或采用选择才保存任务对象。没有选中记录也可直接聊天。
- 同一采购草稿只在最新引用处展示一份可操作卡片，旧引用可定位到当前草稿。已完成或冻结的卡片默认展示摘要，可展开明细；编辑和最终确认仍展示完整字段。
- 当前账号收为输入框下方的轻量文字；连接或模型异常才显示状态提示。API 文档和开发调试面板不出现在普通聊天界面。

历史搜索当前仅匹配标题。列表时间为创建时间，尚无会话重命名、删除和分页接口。采购任务采用中性名称，避免将最初页面选择误当作后续草稿的商品。

## 布局与键盘

默认宽度 420px，分隔条可拖动或用左右方向键调整，每次 20px，范围 340–720px；展开至 900px。视口宽度不超过 640px 时占满视口。

历史、任务、上下文使用 iframe 内原生模态面板，焦点限制在当前面板；打开历史直接聚焦搜索框。Esc 先返回对话，普通聊天中 Esc 收起助手并将焦点退回宿主入口。收起保留会话。

中文输入期间的候选确认 Enter 和旧式组合键码 229 均不会发送消息。该行为有自动测试；本次没有执行跨操作系统的原生中文输入法候选操作，也未覆盖移动设备软键盘，应在相应发布环境补测。

## 验收证据

真实浏览器使用内置虚构 buyer 账号及采购订单页面：

| 检查 | 实际结果 |
| --- | --- |
| 布局宽度 | 340px、默认 420px、展开 900px 均可读，输入框保持可见 |
| 长对话 | 加载既有 18 条消息；只滚动消息区，向上翻阅出现“回到最新” |
| 历史搜索 | “可乐”匹配已有标题；无匹配关键词显示空态 |
| 空白会话 | 新建后欢迎内容与原会话分离；未发送时历史数量不增加 |
| 首次发送 | Enter 发送一条验收问候；真实模型返回问候，标题与历史新增一条；没有创建业务任务 |
| 换行与导航 | Shift + Enter 保留换行；可切回旧会话并查看原有消息和采购卡片 |
| 任务与上下文 | 只列当前会话任务，可选择和退出；无 ERP 选择时新建上下文任务按钮禁用 |
| 卡片 | 已完成订单摘要显示商品、数量、金额与执行结果，完整明细可展开 |
| 键盘与焦点 | Esc 退出历史面板后保持助手展开；聊天中 Esc 收起并聚焦宿主入口 |

本次没有确认或创建 ERP 订单，没有审核、入库或付款操作。既有订单用于只读显示验收。会话列表仍受原 owner 与会话代次校验；`GET /conversations` 向后兼容增加 `created_at` 并为默认标题返回首条本人用户消息摘要，不调用模型、不更新存储标题、不增加数据库迁移。

自动验证：后端 188 项通过（含 PostgreSQL 会话标题、顺序、租户与代次回归），前端 13 项通过，TypeScript 与生产构建、Ruff、OpenSpec 严格校验及差异空白检查通过。前端新增覆盖搜索、草稿引用去重、受限任务名称和输入法/换行提交保护。

运行环境已重建 API/worker 和网页镜像。本次布局验收不代替 [采购验证](purchase-verification.md)、[采购故障恢复验收](purchase-recovery-verification.md) 及 OpenSpec 中剩余的账号切换、专业委派、完整编辑、跨模块和发布验收。

```sh
npm test --prefix frontend
npm run build --prefix frontend
A4J_RUN_PG_TESTS=1 uv run --project backend pytest backend/tests
openspec validate add-contextual-erp-assistant --strict
```

启动与更新见 [开发指南](development.md)。浏览器操作以虚构数据环境为前提，切换会话和查看卡片均无需触发采购确认。
